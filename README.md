## What This Engine Does

Resonance Fold is a **dual-capability** structural engine:

1. **Standalone de novo folding (ML-independent):** Given only a primary sequence, the engine synthesizes a complete backbone structure through golden-ratio lattice initialization, torsion-space kinematics, and resonance stabilization — with **zero neural-network inference, no learned weights, no multiple sequence alignments, and no structural templates**, executing on consumer hardware in seconds. Results ship as a packaged bundle (PDB + JSON manifest with convergence telemetry). The public Hugging Face deployment exposes exactly this flow.
2. **Campaign refinement mode (as used in CASP17):** The same deterministic core refines decoys generated by deep generative models (Boltz-2 diffusion, ESMFold via NVIDIA NIM), replacing molecular-dynamics energy minimization outright.

**In CASP17, this pipeline processed 137 targets with full five-model submissions (plus ensembles) and 30 early-season targets partially — 602 submitted models — spanning monomers, high-order multimers, RNA–water/ion complexes, ligand docking, and multi-state ensembles, all orchestrated by a human–agent tandem on a consumer laptop GPU.**

All stereochemical improvements derive from **Step 1 (steric clash resolution)**; **Step 2 (TTT-7) is a parity stabilization that preserves those improvements** (see below). Known-structure control benchmark (KRAS–sotorasib, PDB 6OIM, ligand pocket pipeline): **100% pocket residue recall** (30/30, zero false negatives; 17 additional residues localized to the adjacent GDP/Mg²⁺ cofactor region; F1 = 0.779).

## How the Refinement Pipeline Works (Deterministic, Reversed Order)

Standard pipelines minimize energy before (or instead of) resolving clashes. This engine reverses it:

1. **Step 1 — Steric clash resolution.** An exact 3D KD-tree (O(N log N)) enumerates non-bonded atom pairs with sequence separation |i−j| ≥ 2 closer than 1.10 Å. Clashing atoms are displaced radially along normalized pairwise unit vectors while backbone dihedrals are held invariant (δφ = δψ = δω = 0); steric relief passes exclusively to side-chain rotamers (χ1–χ5). Secondary structure is preserved by construction.
2. **Step 2 — Parity stabilization (TTT-7).** A deterministic formatting/parity pass applies a bounded search over sub-ångström rigid translations (≤ 0.2 Å worst case) so that each model satisfies the engine's structural checksum convention. Because it is a rigid translation, no internal geometry metrics change — bond lengths, angles, and every pairwise distance of the input decoy are preserved exactly.
3. **Step 3 — Gateway calibration.** B-factor records clamped to [0.00, 98.50] for strict 80-column PDB compliance; PARENT N/A / TER chain boundaries; ensemble `populations.txt` normalized to Σpᵢ = 1.0000.

## The Mathematical Stack

| Component | Mechanism | Role |
|---|---|---|
| Golden-ratio spiral initialization | angular increment 2π/φ² (137.507764°), rigid 3.8 Å Cα spacing | phase-drift-free backbone seeding for repeated subunits |
| QRT attractor | arctan(4/π) ≈ 51.8273° | locks helical packing angle to the analytic attractor |
| Frenet–Serret frames | curvature + torsion forward kinematics | continuous backbone assembly from internal coordinates |
| Steric repulsion | 1/d¹² non-bonded potential + hydrophobic wells (6.5–7.0 Å) | clash-free packing guidance |
| Debye–Hückel screening | U(d) = q₁q₂/d · e^{−κd}, κ = 0.1 Å⁻¹ | physiological salt screening (~150 mM) |
| Flory compaction | Rg = 2.2·N^0.38 | size-appropriate radius of gyration target |
| Optimizer | L-BFGS-B (gtol 1e-7, ftol 1e-10) | deep local minima, analytic gradients (PyTorch→SciPy bridge) |
| TTT-7 auditor | deterministic structural parity checks | post-hoc integrity verification of every submitted structure |
| KD-tree clash resolver | SciPy cKDTree (vectorized) + rigid backbone rule | deterministic clash elimination |

## Quickstart

### Option 1: Live demo (no install)
Open the Hugging Face Space: **https://huggingface.co/spaces/Nexus-Resonance-Codex/NRC-CASP-17-ENGINE** — paste a sequence, receive a zip bundle containing the refined PDB and manifest.

### Option 2: Local (Docker)
```bash
docker build -t nrc-casp17-engine .
docker run -p 7860:7860 nrc-casp17-engine
```

### Option 3: Local (Python)
```bash
uv venv .venv && . .venv/bin/activate
uv pip install -r requirements.txt
python run_tests.py   # verify determinism and pipeline integrity
python app.py         # launch the Gradio interface
```
